# Contributing

Thanks for helping improve smallwebp.io. This repository tracks problems and ideas; the site's source code isn't published here.

## Reporting a problem

Use the [bug report form](https://github.com/popcornbag8891-blip/SmallWebP/issues/new?template=bug_report.yml). The most useful reports include:

- the browser and device,
- the file type and roughly how large it was,
- the mode and settings you used,
- what you expected and what happened instead.

Please **don't attach private images**. Issues are public. If the problem only happens with one file, try to reproduce it with an image you're happy to share.

## Suggesting an idea

Use the [feature request form](https://github.com/popcornbag8891-blip/SmallWebP/issues/new?template=feature_request.yml). Search existing issues first; a 👍 on an existing request helps more than a duplicate.

## What guides decisions

- **Nothing is uploaded.** Ideas that need a server to see your images won't be added.
- **Real numbers only.** Sizes, savings and timings shown on the site are measured, never estimated.
- **Honest results.** If a file gets bigger, the site says so.

## Code of conduct

Be kind and assume good intent. Harassment or abuse leads to removal from the project.
